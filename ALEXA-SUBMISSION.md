# Alexa+ simulation positioning

Current requirements, reviewer handles and submission gates are in SUBMISSION-CHECKLIST.md, checked against the official rules and FAQ on 21 October 2026. SUBMISSION-DRAFTS.md contains the factual project description, architecture, feedback prompts and narration.

SIR demonstrates the intended Alexa+ consumer advocate through a web interface. Its offline provider recognises the three Acorn messages. The case engine, original-source retention, comparison, draft revisions, explicit approval, unsent email export and outcome history are implemented. There is no live Alexa device connection, voice capture, MCP server, inbox access or email sending.

The rules explicitly permit an AI/agentic simulated experience instead of a live Alexa+ runtime hook. That allowance does not establish that this particular bounded rehearsal has been accepted by the organizer. The optional live intake implementation exists but was not verified with a real API call in this release session. Keep these boundaries explicit in the video and submission.
